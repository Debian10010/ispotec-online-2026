          envia HTML, causando o erro "headers already sent".

Solução:  Reorganizar ficheiros para fazer validações ANTES de incluir header.

================================================================================
                           SE AINDA HÁ ERROS
================================================================================

Se ainda receber "headers already sent", verifique:

1. Procure por espaços em branco ANTES de <?php ou DEPOIS de ?>
   - Remova todo espaço/quebra linha após ?>

2. Verifique se include files (config/database.php) não têm output
   - Não devem ter HTML, apenas PHP puro

3. Verifique ordem:
   - Primeiro: require ficheiros de config
   - Depois: validações com header()
   - Por último: require header.php

4. Use ob_start() como último recurso:
   - Coloque ob_start(); na primeira linha
   - Coloque ob_end_flush(); na última linha
