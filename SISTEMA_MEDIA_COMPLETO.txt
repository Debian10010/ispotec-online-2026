  3. BANCO DE DADOS
═══════════════════════════════════════════════════════════════════

📊 scripts/criar_tabelas_media.sql

Tabela: chat_messages
├─ id (INT, PK, AUTO_INCREMENT)
├─ user_id (INT, FK → users.id)
├─ group_id (INT, FK → groups.id, NULL = chat global)
├─ conteudo (TEXT)
├─ tipo_mensagem (ENUM: texto, imagem, video, audio, documento)
├─ ficheiro_path (VARCHAR 255)
├─ ficheiro_nome (VARCHAR 255)
├─ ficheiro_tamanho (INT)
├─ data_criacao (TIMESTAMP)
└─ Índices: user_id, group_id, data_criacao

Tabela: chat_files (Metadados)
├─ id (INT, PK, AUTO_INCREMENT)
├─ message_id (INT, FK → chat_messages.id)
├─ tipo_ficheiro (VARCHAR 50)
├─ caminho_ficheiro (VARCHAR 255)
├─ nome_original (VARCHAR 255)
├─ tamanho_ficheiro (INT)
├─ duracao (INT - segundos)
├─ largura (INT - pixels)
├─ altura (INT - pixels)
├─ data_upload (TIMESTAMP)
└─ Índice: message_id

  8. COMO USAR
═══════════════════════════════════════════════════════════════════

PASSO 1: Instalar
   ➜ Abrir: http://localhost/ispotec.online/install-media.php
   ➜ Clicar: "Instalar Sistema de Média"
   ➜ Aguardar confirmação

PASSO 2: Chat Global
   ➜ Dashboard → Chat Global
   ➜ Clicar ícone 📎 para selecionar ficheiro
   ➜ (Opcional) Digitar mensagem
   ➜ Clicar "Enviar"

PASSO 3: Chat de Grupo
   ➜ Dashboard → Meus Grupos
   ➜ Abrir um grupo
   ➜ Clicar "💬 Abrir Chat"
   ➜ Mesmas funcionalidades do chat global
