PASSO 1: INSTALAR SISTEMA DE MÉDIA
===================================================================
1. Abra: http://localhost/ispotec.online/install-media.php
2. Clique em "Instalar Sistema de Média"
3. Aguarde mensagem de sucesso

✅ Instalado:
   - Tabela chat_messages (com suporte a ficheiros)
   - Tabela chat_files (metadados)
   - Pasta uploads/chat/ (armazenamento)


PASSO 2: USAR CHAT GLOBAL COM UPLOAD
===================================================================
1. Login com: admin@ispotec.online / Admin123!
2. Vá para: Dashboard → Chat Global
3. Ou acesse direto: dashboard/chat-global.php
4. Clique no ícone 📎 para selecionar ficheiro
5. Tipos permitidos:
   - 🖼️ Imagens: JPG, PNG, GIF, WebP (até 10 MB)
   - 🎥 Vídeos: MP4, AVI, MOV, MKV, WebM (até 100 MB)
   - 🎵 Áudios: MP3, WAV, OGG, M4A, AAC (até 50 MB)
   - 📄 Documentos: PDF, Word, Excel, PowerPoint, TXT (até 50 MB)


PASSO 3: USAR CHAT DE GRUPO COM UPLOAD
===================================================================
1. Vá para: Dashboard → Meus Grupos
2. Abra um grupo
3. Clique no botão "💬 Abrir Chat"
4. Mesmas funcionalidades do chat global
5. Visualize membros na barra lateral

TROUBLESHOOTING
===================================================================
Problema: "Erro ao fazer upload"
Solução:
  - Verificar pasta uploads/chat/ existe
  - Verificar permissões 755
  - Verificar espaço em disco

Problema: "Tipo de ficheiro não permitido"
Solução:
  - Extensão deve estar na lista permitida
  - Ver MEDIA_UPLOAD_SETUP.md para adicionar extensões

Problema: Ficheiros não aparecem
Solução:
  - Executar install-media.php de novo
  - Verificar permissões de pasta
  - Verificar tabelas foram criadas (chat_messages, chat_files)
