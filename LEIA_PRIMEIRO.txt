OPÇÃO 1: INSTALAÇÃO AUTOMÁTICA (RECOMENDADO)
═════════════════════════════════════════════

1. Coloque os ficheiros em: C:\xampp\htdocs\ispotec.online\

2. Inicie XAMPP (Apache + MySQL)

3. Aceda a: http://localhost/ispotec.online/install.php

4. Siga os 4 passos do assistente de instalação

5. Pronto! Aceda a: http://localhost/ispotec.online/


OPÇÃO 2: INSTALAÇÃO MANUAL
═══════════════════════════

1. Coloque os ficheiros em: C:\xampp\htdocs\ispotec.online\

2. Inicie XAMPP

3. Abra phpMyAdmin: http://localhost/phpmyadmin

4. Cole o conteúdo de scripts/criar_tabelas.sql e execute

5. Edite config/database.php se necessário:
   - $host = 'localhost'
   - $user = 'root' (MySQL user)
   - $password = '' (deixe vazio para XAMPP)
   - $db_name = 'ispotec_online'

6. Aceda a: http://localhost/ispotec.online/

PROBLEMAS COMUNS
════════════════

❌ "Erro de ligação à Base de Dados"
→ Verifique se MySQL está activado no XAMPP
→ Verifique as credenciais em config/database.php

❌ "Classe não encontrada"
→ Certifique-se que todos os ficheiros estão na pasta correcta

❌ Instalação travada no Passo X
→ Recarregue a página (F5)
→ Verifique a consola do navegador (F12)
