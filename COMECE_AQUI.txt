1. INSTALAÇÃO (3 PASSOS SIMPLES)
═════════════════════════════════

   PASSO 1: Extrair para pasta do servidor
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   PASSO 2: Executar instalador automático
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4. COMO USAR COMO ADMIN
═══════════════════════

   Ao entrar no dashboard como admin:
   
   → Dashboard mostra:
      • Número de utilizadores aprovados
      • Utilizadores pendentes (para aprovar)
      • Total de grupos/disciplinas criadas
      • Total de publicações
   
   → Ações disponíveis:
      1. "Gerir Utilizadores Pendentes" 
         Aprove novas contas de utilizadores
      
      2. "Ver Todos os Utilizadores"
         Veja lista completa de utilizadores registados
      
      3. "Gerir Disciplinas/Grupos"
         Crie novas disciplinas (grupos)


5. COMO USAR COMO UTILIZADOR NORMAL
════════════════════════════════════

   Ao registar-se:
   
   1. Aceda a: auth/register.php
   2. Preencha:
      - Nome completo
      - Email
      - Tipo (Estudante/Docente/Especialista)
      - Curso e Nível académico
      - Password (mínimo 8 caracteres)
   
   3. Aguarde aprovação do administrador
   
   Após aprovação:
   
   1. Login em: auth/login.php
   2. Aceda ao Dashboard
   3. Ações disponíveis:
      → "Meus Grupos" - Entrar em disciplinas
      → "Feed Geral" - Ver publicações de todos
      → "Ver Meu Perfil" - Editar dados pessoais
      → "Chatbot Académico" - Fazer perguntas


6. PROBLEMAS COMUNS
═══════════════════

   ❌ "Erro de ligação à Base de Dados"
   
   Solução:
   • Verificar se MySQL está ativo (XAMPP Control Panel)
   • Verificar credenciais em config/database.php
   • Executar test-connection.php para diagnóstico
   
   
   ❌ "Classe não encontrada"
   
   Solução:
   • Garantir que todos os ficheiros estão na pasta certa
   • Reexecute o instalador (install.php)
   
   
   ❌ "Não conseguo fazer login"
   
   Solução:
   • Verificar se a conta foi aprovada pelo admin
   • Para teste, use: admin@ispotec.online / Admin123!
   
   
   ❌ "Instalação não funciona"
   
   Solução:
   • Limpar cache (Ctrl+Shift+Del)
   • Recarregar página (Ctrl+F5)
   • Executar novamente install.php
