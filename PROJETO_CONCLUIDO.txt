RESUMO EXECUTIVO
═══════════════════════════════════════════════════════════════════════════════

Foi desenvolvida uma plataforma completa de rede social académica institucional
em PHP puro com MySQL, específica para o Instituto Superior Politécnico de
Tecnologias e Ciências (ISPOTEC).

A plataforma oferece funcionalidades de colaboração académica, gestão de perfis,
portfólios digitais e suporte inteligente através de um chatbot.

ESTRUTURA TÉCNICA
═══════════════════════════════════════════════════════════════════════════════

LINGUAGEM: PHP 7.4+ (Puro, sem frameworks)
BANCO DE DADOS: MySQL 5.7+
INTERFACE: HTML5 + CSS3 + JavaScript vanilla
SERVIDOR: Apache com .htaccess

CLASSES IMPLEMENTADAS:
- Database.php - Conexão e gerenciamento de BD
- Auth.php - Autenticação e validação
- User.php - Gestão de utilizadores
- Group.php - Gerenciamento de grupos
- Post.php - Sistema de publicações
- Comment.php - Sistema de comentários
- Portfolio.php - Gestão de portfólios
- Chatbot.php - Sistema de chatbot

FICHEIROS DE CONFIGURAÇÃO:
- config/config.php - Constantes e configurações
- config/database.php - Dados de conexão
- includes/header.php - Template de cabeçalho
- includes/footer.php - Template de rodapé

PÁGINAS PRINCIPAIS:
- index.php - Página inicial
- auth/* - Autenticação
- dashboard/* - Painel de controlo
- profile/* - Gestão de perfis
- users/* - Diretório de utilizadores
- chatbot/* - Sistema de chatbot

INSTALAÇÃO E DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════════

PASSOS:
1. Copiar ficheiros para C:\xampp\htdocs\ispotec.online\
2. Criar BD: mysql> CREATE DATABASE ispotec_online CHARACTER SET utf8mb4;
3. Executar: mysql> source scripts/criar_tabelas.sql;
4. Ajustar: config/database.php com credenciais
5. Aceder: http://localhost/ispotec.online/

PRODUÇÃO:
