===============================================================
FLUXO DE FUNCIONAMENTO
===============================================================

Para Capturar Foto:
1. Clique botão 📷
2. Na modal: Clique "Iniciar"
3. Clique "Capturar" para tirar foto
4. Veja prévia e clique "Enviar"
5. Clique "Enviar" no chat para enviar

Para Gravar Áudio:
1. Clique botão 🎙️
2. Na modal: Clique "Gravar"
3. Fale no microfone (contador mostra tempo)
4. Clique "Parar" para terminar
5. Clique "Ouvir" para prévia
6. Clique "Enviar" para aceitar
7. Clique "Enviar" no chat para enviar

Cancela em Qualquer Momento:
- Botão "Sair" = fecha a modal sem enviar
- Botão "✕" = remove ficheiro do preview
- Botão "Retomar" = começa de novo

===============================================================
ESTRUTURA DE CÓDIGO
===============================================================

Cada modal contém:
- Video element para câmera
- Canvas para captura de imagem
- Audio element para playback
- MediaRecorder API para gravação
- Lógica de estados e transições
- Conversão Blob para File
- Integração FormData

Variáveis globais:
- mediaRecorder: gravador de áudio
- audioChunks: chunks de áudio
- mediaStream: fluxo de câmera/áudio
- capturedImageBlob: imagem capturada
- capturedAudioBlob: áudio capturado
- timerInterval: intervalo para contador
