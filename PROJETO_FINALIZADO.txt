PROBLEMA 1: "session_start(): Ignoring session_start()"
│
├─ Localização: header.php, check-auth.php
├─ Causa: Múltiplas chamadas a session_start()
├─ Solução: Implementar session_status() === PHP_SESSION_NONE
└─ Status: ✓ RESOLVIDO


PROBLEMA 2: "mysqli object is already closed"
│
├─ Localização: dashboard/my-groups.php, group-view.php, index.php
├─ Causa: Conexão fechada prematuramente com closeConnection()
├─ Solução: Implementar padrão Singleton para Database
│          └─ Uma única instância reutilizável
│          └─ Sem fechar a conexão
├─ Ficheiros Afetados: 4
└─ Status: ✓ RESOLVIDO


PROBLEMA 3: Chat Global Inexistente
│
├─ Localização: dashboard/
